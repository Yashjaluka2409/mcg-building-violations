Fonts used by the notice/order PDF generator (bilingual Hindi/English).
- NotoSansDevanagari-Variable.ttf  (SIL Open Font License) - Devanagari
- NotoSans-Variable.ttf            (SIL Open Font License) - Latin
Source: https://github.com/google/fonts/tree/main/ofl
WeasyPrint (Pango) shapes Devanagari correctly with these; the reportlab fallback renders English only.
